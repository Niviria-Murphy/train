一、项目概要

里德伯中性原子（Rydberg neutral-atom）是当下最具可扩展潜力的量子硬件路线之一，但把量子算法真正"跑"在原子阵列上，需跨越「算法 → 编译 → 脉冲 → 保真 → 部署」的鸿沟。现有工具链在编译、控制、门原语三层彼此割裂，导致端到端保真度损失大、使用门槛高。本项目「量脉 QuantPulse」提出"编译–控制–门"一体化的全栈控制软件，以"控制即服务（CaaS）"形态交付：将量子算法编译为保留对角相位的相位超图，用切比雪夫–变分蒙特卡洛（Chebyshev–VMC）反绝热驱动生成抗噪脉冲，并以无交叉回声 RAP 门实现 CZ 保真度 >0.9999、CCZ >0.999。项目已构建可演示前端原型，验证设计思路与可视化效果，目标为量子硬件厂商、高校实验室与企业算法团队提供低门槛的高保真控制能力。

二、项目背景与痛点

2.1 背景

量子计算进入 NISQ（含噪声中等规模）时代，中性原子平台凭借千量级可扩展量子比特阵列、长相干时间与原生多体里德堡相互作用，成为继超导、离子阱之后的重要路线。但硬件优势要转化为可用算力，关键瓶颈在软件层——如何把高层算法高效、保真地编译为原子机可直接执行的激光脉冲序列。

2.2 核心痛点

  • 编译层割裂：主流编译把多体对角相位"拍平"为 2 比特门序列，浪费中性原子原生多体相互作用能力，门数与误差显著上升。
  • 控制层昂贵：反绝热（counter-diabatic）驱动需近似奇异的 AGP 算符，传统方法系数复杂度随系统规模指数增长，难以在经典硬件实时生成。
  • 门原语受噪：激光强度/失谐涨落直接侵蚀双比特门保真度，常规脉冲对噪声仅零阶抑制，难达容错阈值附近。
  • 端到端断层：三层工具各自为战，算法研究者与硬件厂商之间缺乏统一控制栈，复用成本与门槛高。

三、项目目标

  • 总目标：构建"编译–控制–门"一体化的中性原子量子机全栈控制软件，以 CaaS 形态降低量子计算使用门槛。
  • 技术目标：原生多体编译占比显著提升；切比雪夫–VMC 将脉冲生成复杂度降至多项式级；CZ/CCZ 保真度分别达到 >0.9999 / >0.999，且在 ±3% Rabi、±1% 失谐涨落下仍达标。
  • 成果目标：可演示软件原型 + 发明专利/软著 + 论文 + 大创结题与竞赛获奖。

四、项目创新点

编号创新点说明（项目核心增量）
1编译–控制联合优化将编译阶段的"原生门决策"直接馈入反绝热脉冲生成，按门类型匹配最优驱动策略，而非三段独立黑箱，显著降低端到端保真度损失。
2切比雪夫统一控制框架用同一套 Chebyshev–VMC 流程统一处理单/多比特反绝热驱动，参数化替换门原语，降低工程复杂度、便于扩展新门型。
3经典可部署的运行栈全部编译与脉冲生成在经典硬件完成，以 CaaS 交付，硬件厂商无需自研编译栈即可调用高保真脉冲。
4噪声三重抑制零面积脉冲（一阶抑制激光强度噪声）+ 时间反演对称（消去动力学相位）+ 切比雪夫正则（压制高频发散）协同，抗噪声鲁棒性优于单点方案。

五、研究内容与技术路线

端到端管线：算法导入编译为相位超图反绝热脉冲生成保真度预估硬件部署。三层方法对应以下研究内容，均基于前沿研究并做原创集成：

① 编译层 · Möbius 相位超图

将 QAOA / QRAM / 对角电路映射为相位超图：节点=原子/比特，超边=多体相位项。调度器依据里德堡阻塞可行性、原子运动与误差代价，决定"原生多比特门执行"或"分解"，释放 3/4 体原生能力。

技术来源：wangjinbo.pdf · Möbius 相位超图编译

② 控制层 · 切比雪夫–VMC 反绝热驱动

频域用第一类切比雪夫多项式一致逼近 AGP 中奇异的 1/ω 算符（配合平方变量替换 + γ 正则 + 奇多项式构造）；前馈神经网络 + 变分蒙特卡洛求解 AGP 矩阵元与基态能量，把系数复杂度从指数压到多项式，全程经典硬件运行。

技术来源：多项式_.pdf · Chebyshev–VMC 反绝热驱动

③ 门原语层 · 无交叉回声 RAP

反对称零面积 Rabi + 对称失谐双脉冲，全程避开能级交叉；时间反演对称天然消去动力学相位，零面积脉冲对激光强度噪声一阶抑制。CZ 保真度 >0.9999、CCZ >0.999，±3% 涨落下仍 >0.999。

技术来源：CZ_gate_PRB12.pdf · 无交叉回声 RAP 门

六、产品与系统方案

产品以 Web 端 CaaS 形态交付：用户导入算法（QASM / 对角电路）→ 在线查看编译后的相位超图 → 一键触发反绝热脉冲生成 → 查看保真度与噪声鲁棒性报告 → 导出可下发指令序列。当前进度已构建可演示前端原型（单页流水线播放器，含相位超图、脉冲波形、保真度曲线的可视化），用于验证设计思路与展示效果；后续工程化阶段将后端算法引擎（Möbius 编译 / Chebyshev–VMC 驱动 / RAP 门原语）以可插拔服务接入。

面向对象领域建模

Algorithm / PhaseHypergraph / Hyperedge / AntidiabaticPulse / FidelityReport 建模为对象，物理派生指标在对象内计算，便于测试与复用。

可插拔控制栈

前端与算法引擎经契约解耦，后端就绪后仅替换传输层，页面与状态零改动，降低联调风险。
